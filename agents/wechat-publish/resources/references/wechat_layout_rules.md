# 微信公众号移动端版式规则

## 1. 基础尺寸

- 设计视口：375–414px。
- 正文：15–16px；信息密集文章可用 15px，叙事文章优先 16px。
- 正文行高：1.75–2.0。
- 段间距：14–22px。
- 模块间距：24–40px。
- 一级章节间距：40–56px。
- 卡片圆角：8–16px，同篇保持一套尺度。
- 外层左右内边距：16–20px。

文字使用深灰而不是纯黑；正文与背景对比度至少 4.5:1。

## 2. 阅读节奏

推荐节奏：普通正文 → 重点/卡片 → 正文 → 图片 → 导航/标题 → 正文 → 引用/数据 → 分割。每 2–4 个普通段落出现一次节奏变化，但不要为了节奏改写或拆分原文。

## 3. 标题与导航

- 一级标题前留 36–48px，后留 14–22px。
- 章节导航紧跟一级标题，后留 20–28px。
- 二级标题前留 28–36px，后留 12–18px。
- 三级标题前留 20–28px，后留 8–12px。

所有同级标题共享同一参数。章节导航不能替代正文中的二级标题。

## 4. 图片

- 使用 `display:block;width:100%;max-width:100%;height:auto`。
- 上下留白 20–32px。
- 保持原始比例，不强制固定高度，不裁切重要信息。
- 图片说明仅使用原文已有说明；没有说明就不新增。

## 5. 卡片和表格

卡片内部留白 14–20px。大段正文不要全部塞进卡片。宽表格在手机端可改为纵向卡片，但必须保留单元格文字、字段关系与顺序。

## 6. CTA、二维码和互动区

- 原文已有报名、联系、阅读原文、二维码或互动内容时，设计为清晰收尾区域。
- 原文没有相关内容时，不自动写入正文；在 HTML 外作为可选运营建议。
- 二维码图片属于原图，必须保留；无法提取时在原位置标注对应图片序号。

## 7. 微信兼容

- 正文样式以内联 CSS 为主。
- 使用 `section`、`p`、`span`、`strong`、`img`、`table` 等稳健标签。
- 禁止 JavaScript、外链字体、复杂动画、固定定位、横向滚动和多层复杂布局。
- 不依赖伪元素承载关键信息；重要结构用边框、色块和空元素实现。
- 即使渐变或阴影被过滤，标题和卡片仍应凭底色、边框、留白保持层级。

## 8. 交付 HTML

输出完整 HTML 预览。文章正文根节点保持单列、移动端宽度和内联样式。设计分析、摘要建议、封面建议和自检结果放在 HTML 外，避免污染正文保真检查。
