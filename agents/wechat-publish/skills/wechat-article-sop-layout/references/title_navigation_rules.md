# 主标题与章节导航规则

## 1. 微信公众号主标题

微信公众号后台有独立标题输入框。若文档第一行是文章主标题，默认不在正文 HTML 中重复展示。

主标题只用于：

- 判断主题、行业和视觉风格。
- 生成封面建议与摘要建议。
- 理解文章整体结构。

用户明确说“正文中也保留标题”时才展示。

## 2. 主标题识别

按以下信号判断：

1. Word 的 `Title/标题` 样式。
2. 文档元数据标题。
3. 第一行位于所有正文之前、语义覆盖全文、且为唯一最高级标题。

如果无法可靠区分主标题和正文第一个一级标题，宁可保留并在自检中说明，不得误删正文标题。

## 3. 正文标题

- 一级标题：使用强识别的章节标题组件。
- 二级标题：在章节导航中出现副本，并在正文原位置保留独立样式。
- 三级标题：在正文原位置使用轻量标签、短线或底纹。

不要自动添加编号，不要把正文句子提升为标题。

## 4. 二级标题导航

对每个一级标题，收集其后、下一个同级或更高级标题之前的所有二级标题。存在二级标题时，在该一级标题下方生成导航。

导航文字必须逐字复制原标题，不能改写、缩写、总结或新增。

可根据风格选择：

- 树状思维导图。
- 分支线条目录。
- 胶囊标签组。
- 卡片式目录。
- 时间轴目录。
- 左侧竖线目录。
- 网格标签目录。
- 科技节点或商务章节目录。

导航必须体现“一级标题统领多个二级标题”的关系，不能只是普通项目符号列表。正文中的二级标题仍须在原位置出现。

## 5. 选择逻辑

- 科技文章：节点线、网格或 HUD 导航。
- 商务报告：竖线、编号感但不新增编号、细边框目录。
- 教育科普：圆角胶囊、轻卡片或步骤节点。
- 活动文章：时间轴、议程卡或亮点标签。
- 品牌故事：杂志式细线、留白卡或品牌纹理导航。

同篇只使用一种导航家族。
