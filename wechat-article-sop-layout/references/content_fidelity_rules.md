# 内容保真规则

## 1. 零修改原则

将用户文档视为正文唯一事实来源。除非用户明确要求编辑文案，否则必须逐字保留：

- 标题、段落、列表、引用、表格、脚注与注释。
- 数字、日期、时间、金额、百分比和单位。
- 公司名、产品名、人名、地名、专有名词和英文。
- 标点、大小写、重复句、错别字和原有换行关系。

禁止删除、增加、改写、总结、扩写、合并段落、拆句、调换顺序或“顺手纠错”。

## 2. 允许改变的内容

只允许改变 HTML 标签、内联样式、视觉布局、颜色、边框、卡片、分割线、图标、留白、背景和非文字装饰。可以将一个完整原文段落包入卡片，但不能改动段落内容。

## 3. 新增文字边界

正文中唯一允许重复的原文文字，是章节导航里逐字复制的二级标题。不得新增“本章导读”“核心观点”“总结”等标签。

封面建议、摘要建议、使用说明和自检结果放在 HTML 外。这些属于交付说明，不计入正文。

## 4. 源内容清单

排版前按顺序记录：

1. 文档主标题候选。
2. 一级、二级、三级标题和从属关系。
3. 每个正文块的原始文字。
4. 列表和表格结构。
5. 图片锚点及相邻文本。

不要只读取摘要、目录或局部预览。

## 5. 反向核验

交付前：

1. 去除 HTML 标签、样式和空装饰元素。
2. 去除章节导航中重复的二级标题副本。
3. 去除已确认且按规则不展示的文档主标题。
4. 将剩余文字块按顺序与源内容清单逐项比较。

缺字、多字、错字、错序、数字或名称变化均为阻断错误。Content Fidelity 未达到 100% 时不得交付。
