# 风格矩阵

先按行业选择基础风格，再根据内容类型、读者和传播目的微调。不要机械套用。

## 1. 行业与推荐风格

| 内容 | 推荐配色 | 视觉语言 | 常用组件 |
|---|---|---|---|
| AI / 科技 / 网络安全 | 深蓝、青蓝、紫蓝、银灰 | 网格、数据流、HUD 线框、发光边界 | 科技标题、节点导航、线框卡、数据卡、渐变分隔 |
| 金融 / 商务 / 行业分析 | 墨绿、深蓝、金色、高级灰 | 细线、稳定网格、报告感、大留白 | 报告标题、数据卡、商务引用、细边框卡 |
| 教育 / 知识科普 | 蓝白、浅绿、奶油色 | 友好、清晰、课堂笔记感 | 圆角标题、概念卡、步骤卡、轻量图标 |
| 医疗 / 健康 | 青绿、蓝白、低饱和灰 | 洁净、可信、克制 | 信息提示卡、流程卡、细线图标 |
| 活动 / 发布会 | 品牌渐变、亮色强调 | 海报感、节奏强、信息聚焦 | 议程时间轴、嘉宾卡、亮点卡、原文 CTA |
| 品牌宣传 / 企业故事 | 品牌主色、中性色、金属色 | 杂志感、大图、品牌纹理 | 杂志标题、金句卡、大图框、品牌分隔 |
| 年度总结 / 数据报告 | 深浅对比、深蓝金、黑金 | 报告感、里程碑、数字戏剧化 | 大数字、时间轴、成就卡、总结区 |
| 招聘 / 人物采访 | 暖色、莫兰迪、品牌色 | 人物感、故事感、温和 | 人物卡、问答框、标签信息、照片卡 |
| 环保 / 公益 | 绿色、土色、天空蓝 | 自然、开放、轻量 | 生态纹理、故事卡、行动区 |

## 2. 配色系统

使用角色化颜色：

- `canvas`：整篇背景。
- `surface`：正文和卡片底色。
- `ink`：主文字。
- `muted`：次级信息。
- `primary`：标题、导航主干、关键边线。
- `accent`：小面积高光、节点或 CTA。
- `line`：边框和分割线。

彩色相通常不超过 2 个。主色用于统一，强调色面积控制在约 10% 以内。不要默认使用蓝色；优先从 `assets/color_palettes/palettes.json` 选取并按品牌色调整。

## 3. 标题系统

- 一级标题：左侧竖条、横幅、卡片、渐变、科技线框、杂志、报告或新中式。至少包含文字层与两种非文字装饰结构。
- 二级标题：ICON 标签、左线、色块、胶囊、节点、细边框或下划线。强度低于一级标题。
- 三级标题：短横线、圆点、浅底或加粗文字。保持轻量。

不得为原标题自动添加 01/02，除非原文已有编号。

## 4. 导航系统

根据风格选择树状分支、节点线、胶囊标签、卡片目录、时间轴、竖线目录、网格标签或科技节点。导航文字只能逐字复制原有二级标题。

## 5. 卡片系统

可选浅底卡、白色阴影卡、渐变卡、细边框卡、科技线框、商务信息、数据、案例、Tips、步骤、问答、金句卡。只包裹完整原文内容，不创造卡片标题或解释文字。

## 6. 引用系统

可选左竖线、浅底、对话框、金句、科技线框、商务细线或半透明引用。仅在源内容确属引用、问答或重点短句时使用。

## 7. 分割线系统

可选极简细线、渐变、点阵、几何、科技线、品牌纹理、短线或节点连接线。使用空元素、边框或内联 SVG；不要新增可见文字。

## 8. 图片与背景

- 图片：圆角、白边、阴影、卡片、满宽、杂志、科技边框、渐变边框或说明卡。
- 背景：浅网格、粒子、几何、渐变、圆点、波纹、品牌色块、纸张质感。

背景保持低对比；图片处理不得裁掉原图信息或改变顺序。

## 9. 动态组合规则

用“固定骨架 + 可变组件”避免重复：正文参数和可读性是固定骨架；每篇变化标题结构、导航、卡片、分隔、图片框与纹理。单篇最多融合两种风格，其中主风格占约 80%。
